What Is an Import?

An import makes a useful name from another part of Kotlin or another library available in the current file.

Necessary 2-3 minutes Vocabulary: import, library

Code Can Be Reused

Programmers do not write every tool from the beginning. A library is a collection of code prepared for reuse. Kotlin includes a math library, and this course also uses a testing library named Kotest.

Bring One Name into the File

An import line makes a library name available in the current Kotlin file. Import lines go near the top, before function definitions.

import kotlin.math.sqrt

fun main() {
    println(sqrt(81.0))
}

The imported name is sqrt, a function that computes a square root. Once it is imported, the program can call sqrt(81.0) by its short name.

An Import Does Not Run the Function

The import says that the name may be used. It does not call sqrt and does not print anything. The function call inside main does the computation; println displays the result.

You are not expected to memorize long library paths. At first, the important microskill is recognizing an import and finding the usable name at its end.

Practice

  1. Which line makes sqrt available?
  2. Which line actually calls sqrt?
  3. Would the import line by itself display a number?
Check your answers

1. import kotlin.math.sqrt makes the name available.

2. println(sqrt(81.0)) contains the call to sqrt.

3. No. An import makes a name available; it does not call or print anything.

Microskill

Recognize an import line and identify the short name it makes available.

Read It As

import kotlin.math.sqrt means, "This file will use sqrt from Kotlin's math library."
