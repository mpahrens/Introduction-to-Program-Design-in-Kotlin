What Is a Function?

A function gives a name to an action or computation so that a program can ask for it by name.

Necessary 2-3 minutes Vocabulary: function, body, call, argument

A Named Part of a Program

A function is a named computation or action. This definition creates a function named main:

fun main() {
    println("Ready to begin")
}

The keyword fun tells Kotlin that a function is being defined. The name comes next. The parentheses will eventually hold information the function needs. The curly braces enclose the function body: the statements to perform when the function runs.

main Is the Starting Function

A file can define many functions. When we run a simple Kotlin program, Kotlin starts with the specially named main function. The name matters: changing it to start would create an ordinary function, not the program's starting place.

Calling Another Function

The line inside main is a function call. It asks the existing println function to run. The text inside the parentheses is an argument: a value supplied to the function.

println("Ready to begin")
// name     argument

Here, println displays its argument and then moves to a new line. Defining a function describes what it does. Calling a function asks it to do that work now.

Practice

  1. In the example above, what is the name of the starting function?
  2. Which punctuation marks enclose the function body?
  3. In println("Welcome"), what is the argument?
Check your answers

1. The starting function is named main.

2. Curly braces, { and }, enclose the body.

3. The argument is the String value "Welcome".
