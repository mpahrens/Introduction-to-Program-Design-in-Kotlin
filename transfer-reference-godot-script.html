01 / Files, running & debugging

Make a scene. Attach a script. Run it.

Godot Script files use .gd. A script attached to a node participates in the scene’s lifecycle.

A starting file and an entry point

Kotlin
fun main() {
    val name = "Gompei"
    println("Hello, $name!")
}
Godot Script
extends Node

func _ready() -> void:
    var name: String = "Gompei"
    print("Hello, %s!" % name)

Save the script as hello.gd and attach it to the root node of a saved scene. _ready() runs when the node and its children are ready in the scene tree. A function named main has no automatic entry-point role.

  1. Create: create a project in the editor, add a Node as the root of a scene, save the scene, and attach a new script.
  2. Run: use Run Current Scene (F6). Run Project (F5) uses the project’s main scene; select this scene when prompted.
  3. Debug: click beside a line number to set a breakpoint. Run the scene, inspect variables, and use Step Over, Step Into, or Continue.
  4. Read errors: fix script errors shown in the editor first. For a runtime error, inspect the Debugger’s message and stack frames to find the failing call.

Remember: Use Godot Script for the 4.x editor. Each example is independent unless marked otherwise. Put executable statements inside _ready() or another function; put function, class, and enum definitions at script level. Use one consistent indentation style; the editor defaults to tabs.

02 / Names, assignment & scope

Declare a variable; choose its type

Use var for variables and const for compile-time constants.

Binding, inference, and reassignment

Kotlin
val x = 3
var count: Int = 0
count += 1
// x = 4 is a compile error.
Godot Script
const X = 3
var count: int = 0
count += 1
var score := 10
score = 20
# X = 4 is an error.

:= infers a static type; var score = 10 leaves the variable dynamically typed. A type annotation constrains assignments. const requires a constant expression, so it does not replace every use of Kotlin val.

Local names and parameters

Kotlin
fun nextCount(count: Int): Int {
    val next = count + 1
    return next
}
Godot Script
func next_count(count: int) -> int:
    var next: int = count + 1
    return next

Local variables belong to their enclosing block. A variable declared inside an if or loop body is unavailable outside that block. Script-level variables are instance properties, shared by that instance’s method calls.

Remember: Use snake_case for Godot Script variables and functions. A colon starts an indented body. Use # for comments.

03 / Numbers & Booleans

Numbers and Boolean expressions

Int becomes int, Double becomes float, and Boolean becomes bool.

Arithmetic and conversions

Kotlin
val sum = 7 + 2        // 9
val quotient = 7 / 2   // 3
val decimal = 7.0 / 2  // 3.5
val remainder = -7 % 2 // -1
val converted = 7.toDouble()
val parsed = "42".toInt()
val text = 42.toString()
Godot Script
var sum = 7 + 2        # 9
var quotient = 7 / 2   # 3
var decimal = 7.0 / 2  # 3.5
var remainder = -7 % 2 # -1
var converted = float(7)
var parsed = "42".to_int()
var text = str(42)

With two integer operands, division truncates toward zero in both languages; use a float operand for a fractional result. Godot Script may warn about integer division. Its int is signed 64-bit; Kotlin Int is signed 32-bit.

Comparisons and short-circuit logic

Kotlin
val age = 20
val member = false
val offer = age >= 18 && !member
val eligible = age >= 18 || member
val teen = age >= 13 && age < 20
Godot Script
var age = 20
var member = false
var offer = age >= 18 and not member
var eligible = age >= 18 or member
var teen = age >= 13 and age < 20

Both use true, false, and the familiar comparison operators. Godot Script also accepts &&, ||, and !. Short-circuit logic skips an operand when the result is already decided.

Remember: Validate numeric text with is_valid_int() before to_int(); conversion does not provide the same invalid-input failure behavior as Kotlin toInt().

04 / Strings & missing values

Build text; check missing values

String is the text type in both languages. Godot Script string indexing returns a one-character String.

Reading and building text

Kotlin
val name = "Gompei"
name.length             // 6
name[0]                 // 'G'
name.substring(0, 3)    // "Gom"
name.lowercase()        // "gompei"
name.startsWith("Gom")  // true
"  hi  ".trim()         // "hi"
"Hi, $name!"
Godot Script
var name = "Gompei"
name.length()           # 6
name[0]                 # "G"
name.substr(0, 3)       # "Gom"
name.to_lower()         # "gompei"
name.begins_with("Gom") # true
"  hi  ".strip_edges()  # "hi"
"Hi, %s!" % name

substring(start, end) uses an exclusive end in Kotlin; substr(start, length) takes a count in Godot Script. Use == for string contents.

An optional value

Kotlin
val nickname: String? = null
val label = nickname ?: "guest"
val size = nickname?.length
Godot Script
var nickname: Variant = null
var label = nickname if nickname != null else "guest"
var size = null
if nickname != null:
    size = nickname.length()

Godot Script has no String?, safe-call operator, or Elvis operator. A typed String cannot hold null; Variant can. Object references may be null. A conditional expression can choose a fallback.

Remember: Check absence explicitly. An empty string and a missing value communicate different information.

05 / if, when & named choices

Choose a branch or a value

Use if / elif / else for conditions and match for value patterns.

Conditional expressions and ordered tests

Kotlin
fun label(score: Int): String {
    return when {
        score >= 90 -> "high"
        score >= 60 -> "passing"
        else -> "retry"
    }
}
val price = if (age < 18) 5 else 10
Godot Script
func label(score: int) -> String:
    if score >= 90:
        return "high"
    elif score >= 60:
        return "passing"
    else:
        return "retry"

# Given an age variable:
var price = 5 if age < 18 else 10

The first satisfied condition wins. The conditional expression puts the selected value before if in Godot Script. A statement branch does not return its last expression automatically.

Named choices

Kotlin
enum class Signal { STOP, GO }
fun action(signal: Signal): String =
    when (signal) {
        Signal.STOP -> "wait"
        Signal.GO -> "walk"
    }
Godot Script
enum Signal { STOP, GO }

func action(signal: Signal) -> String:
    match signal:
        Signal.STOP:
            return "wait"
        Signal.GO:
            return "walk"
        _:
            return "unknown"

Godot Script enum entries are named integer constants. _ is the wildcard pattern. match is a statement rather than a value-producing expression.

Remember: Do not expect the exhaustive branch checking of a Kotlin enum or sealed hierarchy. Include a deliberate fallback when your function must always return a result.

06 / Function design & testing

Keep the purpose, examples, and tests

Write inputs and outputs first, then implement a function that returns the result.

A purpose and a signature

Kotlin
// Return the ticket cost for a group.
fun cost(count: Int, price: Double): Double {
    return count * price
}
fun greet(name: String = "guest"): String {
    return "Hi, $name!"
}
Godot Script
# Return the ticket cost for a group.
func cost(count: int, price: float) -> float:
    return count * price

func greet(name: String = "guest") -> String:
    return "Hi, %s!" % name

Use func, typed parameters, and -> for the return type. Use -> void for a function with no returned result. Defaults are supported; call arguments are positional rather than Kotlin-style named arguments.

Examples as executable checks

Kotlin
fun main() {
    check(cost(3, 2.5) == 7.5)
    check(cost(0, 2.5) == 0.0)
    check(greet() == "Hi, guest!")
}
Godot Script
func _ready() -> void:
    assert(cost(3, 2.5) == 7.5)
    assert(cost(0, 2.5) == 0.0)
    assert(greet() == "Hi, guest!")
    print("Checks passed")

These checks reuse the functions above. Run the scene in a debug build. A failing assertion stops execution for inspection. Test ordinary cases, boundaries, and every data variant.

Remember: Godot Script assertions are omitted in release builds. Keep necessary work outside assert; use explicit validation for conditions that must be checked in a released program.

07 / Compound data & copies

Represent related fields with a class

A small class can carry the same information as a Kotlin data class.

Define, construct, and select fields

Kotlin
data class Point(val x: Int, val y: Int)
val start = Point(2, 3)
val moved = start.copy(x = 5)
// start.x is 2; moved.x is 5.
Godot Script
class Point extends RefCounted:
    var x: int
    var y: int

    func _init(px: int, py: int) -> void:
        x = px
        y = py

# Inside a function:
var start = Point.new(2, 3)
var moved = Point.new(5, start.y)
# start.x is 2; moved.x is 5.

The inner class definition belongs at script level. _init initializes a new instance; .new(...) constructs it. There is no automatic data-class copy, destructuring, or field-based equality.

Compare the data explicitly

Kotlin
val a = Point(2, 3)
val b = Point(2, 3)
println(a == b) // true
Godot Script
var a = Point.new(2, 3)
var b = Point.new(2, 3)
print(a == b) # false: different objects
print(a.x == b.x and a.y == b.y) # true

These examples reuse Point. Object equality compares identity in Godot Script. Write a comparison function when the meaning of equality depends on fields.

Remember: RefCounted instances are released when no references remain. Their fields are mutable here; preserve a functional design by constructing a new result rather than updating an input.

08 / Sum types & type checks

Model alternatives; inspect their data

Use a shared base class and subclasses to represent different shapes of data.

Define the alternatives

Kotlin
sealed interface Result
data class Success(val value: Int) : Result
data class Failure(val message: String) : Result
Godot Script
class Result extends RefCounted:
    pass

class Success extends Result:
    var value: int
    func _init(v: int) -> void:
        value = v

class Failure extends Result:
    var message: String
    func _init(m: String) -> void:
        message = m

Definitions belong at script level. Use Success.new(42) or Failure.new("missing") to construct an alternative in Godot Script. This hierarchy is open; it does not have the closed-set promise of Kotlin sealed.

Follow the data definition

Kotlin
fun describe(result: Result): String =
    when (result) {
        is Success -> "Value: ${result.value}"
        is Failure -> result.message
    }
Godot Script
func describe(result: Result) -> String:
    if result is Success:
        return "Value: %d" % result.value
    elif result is Failure:
        return result.message
    return "unknown result"

These functions reuse the alternatives above. is checks an object’s type. Handle each alternative’s fields in its branch; choose how to handle unknown alternatives or null.

Remember: A Godot Script Variant is a general value container, not a declaration of a specific closed sum type. Use a clear data definition and tests for each alternative.

09 / Lists & operations

List<T> becomes Array[T]

Array stores an ordered, resizable sequence. Typed arrays constrain the element type.

Construct, index, and combine

Kotlin
val scores: List<Int> = listOf(10, 20, 30)
val empty: List<Int> = emptyList()
scores.size          // 3
scores[0]            // 10
scores.last()        // 30
scores.take(2)       // [10, 20]
scores.drop(1)       // [20, 30]
20 in scores         // true
val more = scores + listOf(40)
Godot Script
var scores: Array[int] = [10, 20, 30]
var empty: Array[int] = []
scores.size()        # 3
scores[0]            # 10
scores[-1]           # 30
scores.slice(0, 2)   # [10, 20]
scores.slice(1)      # [20, 30]
20 in scores         # true
var more = scores + [40]

Both start indexing at zero. Godot Script also accepts negative indices from the end; a slice excludes its end. Addition creates a new array.

Search, order, and compare

Kotlin
val scores = listOf(30, 10, 20)
val index = scores.indexOf(10) // 1
val ordered = scores.sorted()
val same = listOf(1, 2) == listOf(1, 2)
Godot Script
var scores = [30, 10, 20]
var index = scores.find(10) # 1
var ordered = scores.duplicate()
ordered.sort()
var same = [1, 2] == [1, 2] # true

Search returns -1 if absent. Duplicate before sorting to preserve the input. Array equality compares elements in order.

Remember: Array is mutable. Kotlin List exposes read-only operations; keep that design habit by producing new arrays when transforming inputs.

10 / Lambdas, map, filter & fold

Transform, select, and summarize

Use nums = [1, 2, 3, 4] in Godot Script and val nums = listOf(1, 2, 3, 4) in Kotlin.

Map and filter

Kotlin
val squares = nums.map { n -> n * n }
val evens = nums.filter { it % 2 == 0 }
val evenSquares = nums
    .filter { it % 2 == 0 }
    .map { it * it }
// [1, 4, 9, 16]; [2, 4]; [4, 16]
Godot Script
var squares = nums.map(func(n): return n * n)
var evens = nums.filter(func(n): return n % 2 == 0)
var even_squares = nums.filter(
    func(n): return n % 2 == 0
).map(func(n): return n * n)
# [1, 4, 9, 16]; [2, 4]; [4, 16]

Both operations build new collections. Godot Script uses an anonymous func; name the parameter explicitly and write return.

Predicates and a left fold

Kotlin
val hasEven = nums.any { it % 2 == 0 }
val allPositive = nums.all { it > 0 }
val total = nums.fold(0) { acc, n -> acc + n }
val product = nums.fold(1) { acc, n -> acc * n }
// true, true, 10, 24
Godot Script
var has_even = nums.any(func(n): return n % 2 == 0)
var all_positive = nums.all(func(n): return n > 0)
var total = nums.reduce(func(acc, n): return acc + n, 0)
var product = nums.reduce(func(acc, n): return acc * n, 1)
# true, true, 10, 24

The accumulator comes first in the callback. Supply an initial value deliberately. Empty-input any is false and all is true.

Pass a function; call a function value

Kotlin
fun double(n: Int): Int = n * 2
val operation: (Int) -> Int = ::double
val answer = operation(4) // 8
Godot Script
func double(n: int) -> int:
    return n * 2

# Inside a function:
var operation: Callable = double
var answer = operation.call(4) # 8

Use the function name to obtain a Callable and .call(...) to invoke a stored function value.

Remember: Pass double to map; double(4) calls it immediately. Godot Script has no implicit it parameter.

11 / Mutation & shared values

Rebinding versus changing an object

An alias refers to the same collection. Copy deliberately when changes should be independent.

Update elements and size

Kotlin
var count = 1
count += 2
count++
val scores = mutableListOf(10, 20)
scores[0] = 11
scores.add(30)
scores.addAll(listOf(40, 50))
val removed = scores.removeAt(1)
// removed: 20; scores: [11, 30, 40, 50]
Godot Script
var count = 1
count += 2
count += 1 # no ++ operator
var scores = [10, 20]
scores[0] = 11
scores.append(30)
scores.append_array([40, 50])
var removed = scores.pop_at(1)
# removed: 20; scores: [11, 30, 40, 50]

Use pop_at when you need the removed value. remove_at removes without returning it. Mutation methods such as append do not return a replacement array.

Aliases and shallow copies

Kotlin
val original = mutableListOf(1, 2)
val alias = original
val separate = original.toMutableList()
alias.add(3)
// original: [1, 2, 3]; separate: [1, 2]
Godot Script
var original = [1, 2]
var alias = original
var separate = original.duplicate()
alias.append(3)
# original: [1, 2, 3]; separate: [1, 2]

A function receiving an array can mutate the caller’s array. Reassigning its local parameter does not rebind the caller’s variable. A shallow copy shares nested values.

Remember: For nested arrays and dictionaries, duplicate(true) recursively copies those containers. Object elements remain shared; it is not a universal independent copy of every object.

12 / Loops, ranges & input

Loop over values or a range

Use for for a sequence and while for a changing condition.

Elements and indices

Kotlin
val scores = listOf(10, 20, 30)
var total = 0
for (score in scores) {
    total += score
}
for ((index, score) in scores.withIndex()) {
    println("$index: $score")
}
// total is 60.
Godot Script
var scores = [10, 20, 30]
var total = 0
for score in scores:
    total += score
for index in range(scores.size()):
    print("%d: %d" % [index, scores[index]])
# total is 60.

Loop over values when the index is unnecessary. Avoid adding or removing elements from the array being traversed.

Range boundaries and steps

Kotlin
for (i in 1..3) println(i) // 1, 2, 3
for (i in 0 until 3) println(i) // 0, 1, 2
for (i in 1..7 step 2) println(i) // 1, 3, 5, 7
for (i in 3 downTo 1) println(i) // 3, 2, 1
Godot Script
for i in range(1, 4):
    print(i) # 1, 2, 3
for i in range(3):
    print(i) # 0, 1, 2
for i in range(1, 8, 2):
    print(i) # 1, 3, 5, 7
for i in range(3, 0, -1):
    print(i) # 3, 2, 1

range(start, stop, step) excludes stop, including when counting down. break exits the nearest loop; continue skips to its next iteration.

Receive text from an interface

Kotlin
fun main() {
    val word = readln()
    if (word.isNotEmpty()) {
        println(word.uppercase())
    }
}
Godot Script
func _on_text_submitted(word: String) -> void:
    if not word.is_empty():
        print(word.to_upper())

Add a LineEdit node and connect its text_submitted signal to this method on the scripted node. Submitting text calls the method with a String; do not block the scene with a terminal-input loop.

Remember: Scenes respond to callbacks and signals. Keep calculation in small returning functions, and call those functions from input handlers. Use _process(delta) for per-frame work rather than an endless loop inside _ready().
