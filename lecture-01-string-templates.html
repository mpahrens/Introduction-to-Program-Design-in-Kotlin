Build Strings with Templates

Put values and expressions inside a String instead of joining many pieces with +.

Follow-up 2-3 minutes Microskill: use $name and ${expression}

Insert a Named Value with $

A String template includes a value inside text. Put $ before a simple variable name: $name. Kotlin replaces that part with the variable's current value when it builds the String.

The first line prints Hello, Mina!. The second inserts three values into one String. The values are converted to text for the finished String; completed and total are still numbers in the program.

Use ${...} for an Expression

Use braces when you want to compute something rather than insert only a variable. In the example, ${name.uppercase()} produces MINA, and ${total - completed} produces 2. The third line prints MINA has 2 tasks left.

Braces also show where a variable name ends if letters follow immediately. For example, with val place = "Worcester", "${place}shire" produces Worcestershire.

Compare a Template with +

With name = "Mina" and completed = 3, these two expressions build the same String:

String template

val message = "$name completed $completed tasks."

Using +

val message = name + " completed " + completed + " tasks."

Both make Mina completed 3 tasks. The template keeps the words and spaces together, making the finished sentence easier to read. Either result can be given a name, passed to a function, or printed with println(message).

Use $name for a simple name and ${...} for a longer expression or a clear boundary before more letters.

Practice

  1. If val course = "CS1101", what does "Welcome to $course" produce?
  2. If val score = 7, what does "Next: ${score + 1}" produce?
  3. Why use braces in "${place}shire"?
Check your answers

1. Welcome to CS1101.

2. Next: 8.

3. The braces mark the end of place; shire is ordinary text after the value.
