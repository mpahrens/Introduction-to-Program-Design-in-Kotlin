Comparing Strings

String comparisons produce Boolean values, but capitalization and character ordering affect the result.

Optional 2-3 minutes Microskills: ==, <, compareTo

Equality Is Exact

The == operator asks whether two String values contain the same characters in the same order. The comparison is case-sensitive.

"Ada" == "Ada"   // true
"Ada" == "ada"   // false
"Ada" != "Grace" // true

Each comparison is an expression that produces a Boolean value.

Ordering Uses Character Order

Kotlin can also compare Strings with < and >. This resembles dictionary order, but computer character ordering also distinguishes uppercase and lowercase characters.

"ant" < "bee"   // true

For human-facing text, you may want to ignore capitalization. The compareTo method can do that with a named argument:

"Ada".compareTo("ada", ignoreCase = true)   // 0

A result of zero means the Strings compare as equal under the chosen rule. The phrase ignoreCase = true names the argument, making its purpose visible.

Choose the Comparison That Matches the Question

Use == when exact characters matter. Use a case-insensitive operation when capitalization should not matter. Programming requires stating which meaning of "same" the problem needs.

Practice

  1. Predict "Kotlin" == "kotlin".
  2. What type does a String equality expression produce?
  3. What does a zero result from case-insensitive compareTo mean?
Check your answers

1. It produces false because capitalization differs.

2. It produces a Boolean.

3. The two Strings compare as equal when capitalization is ignored.
