What Is a String Object?

A String is a text value with information and useful operations attached to it.

Necessary 3 minutes Vocabulary: object, property, method, index

Text Is More Than Characters

A String is an object: a value that carries information and operations together. Dot notation asks the object for one of those pieces.

val language = "Kotlin"

language.length
language.uppercase()
language.substring(1, 4)

Properties Hold Information

A property is information available on an object. The length property tells how many characters are in a String. It uses no parentheses:

"Kotlin".length   // 6

Methods Perform Operations

A method is a function attached to an object. A method call uses parentheses, which may contain arguments.

"Kotlin".uppercase()        // "KOTLIN"
"Kotlin".substring(1, 4)    // "otl"

Character positions are called indexes, and String indexes begin at 0. For substring(1, 4), position 1 is included but position 4 is not. It takes indexes 1, 2, and 3.

K o t l i n
0 1 2 3 4 5

String methods produce values. They do not print unless their result is passed to println.

Practice

  1. Is length a property or a method?
  2. Predict "program".substring(0, 3).
  3. Which expression produces an uppercase version of "hello"?
Check your answers

1. length is a property; it has no call parentheses.

2. It produces "pro".

3. "hello".uppercase().

Visual Clue

A method call has parentheses. A property access such as .length does not.
