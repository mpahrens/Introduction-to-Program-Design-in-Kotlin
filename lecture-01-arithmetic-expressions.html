Arithmetic Expressions in Kotlin

An arithmetic expression combines number values with operators to produce a new number value.

Necessary 3 minutes Vocabulary: expression, operator, modulo

Expressions Produce Values

An expression is code that produces a value. A number by itself is an expression, and arithmetic can combine smaller expressions into a larger one.

18 + 7
6 * 5
(10 - 4) * 3

The symbols +, -, *, and / are operators. Parentheses group the part that should be computed first, just as they do in mathematics.

The Number Types Affect Division

When both values are Ints, division produces an Int and discards any fractional part. When a Double is involved, the result can include a decimal part.

17 / 5       // 3
17.0 / 5.0   // 3.4

This is not rounding: integer division keeps the whole-number quotient.

Remainder Is Also Called Modulo

The % operator produces the remainder after division. It is also called modulo.

17 % 5       // 2
24 % 6       // 0

A remainder of zero means the first number is evenly divisible by the second.

Practice

  1. Predict (7 + 3) * 2.
  2. Predict 19 / 4 and 19.0 / 4.0.
  3. Which expression tests the remainder when 31 is divided by 10?
Check your answers

1. The result is 20.

2. 19 / 4 produces 4; 19.0 / 4.0 produces 4.75.

3. Write 31 % 10; it produces 1.
