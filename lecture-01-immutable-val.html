Immutable Names with val

A val gives a useful name to a value. That name keeps referring to the same value.

Necessary 2-3 minutes Vocabulary: immutable, initialize, reassign

Name a Result

Programs become easier to read when important values have names. In Kotlin, val creates a name and initializes it with a value.

val credits: Int = 4
val courseName: String = "Calculus I"

Read the first line as, "Let credits be the Int value 4." The colon introduces the name's type. Kotlin can often infer that type, so this shorter version also works:

val credits = 4
val courseName = "Calculus I"

val Names Are Immutable

An immutable name cannot be reassigned after it has been initialized. This code is therefore an error:

val credits = 4
credits = 5   // error: val cannot be reassigned

Immutability gives the reader a useful guarantee: every later use of credits refers to the value chosen on its val line. In a functional style, stable names make calculations easier to follow.

Use the Name in Later Expressions

val pagesRead = 18
val pagesRemaining = 30 - pagesRead
println(pagesRemaining)

The later expression uses the value named pagesRead. It does not change that value.

Practice

  1. What type does Kotlin infer for val floor = 3?
  2. Why is floor = 4 an error after that line?
  3. Write a val named temperature initialized to 21.5.
Check your answers

1. Kotlin infers Int.

2. A val name is immutable and cannot be reassigned.

3. val temperature = 21.5 or val temperature: Double = 21.5.

Microskill

Create a local immutable name with val and use it in a later expression.

Design Benefit

A stable name lets you reason by substitution: wherever the name appears, it means its initialized value.
