Immutable Names with val

A val gives a useful name to a value. That name keeps referring to the same value.

Necessary 2-3 minutes Vocabulary: immutable, initialize, reassign

Name a Result

Programs become easier to read when important values have names. In Kotlin, val creates a name and initializes it with a value.

Immutability gives the reader a useful guarantee: every later use of credits refers to the value chosen on its val line. In a functional style, stable names make calculations easier to follow.

Design Benefit

A stable name lets you reason by substitution: wherever the name appears, it means its initialized value.
