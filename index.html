CS1101 Kotlin Microskill Readings

Short, plain-language prep pages for an introductory Kotlin course in the How to Design Programs style. Each page introduces vocabulary and microskills for the upcoming class.

2 to 3 minutes each No prior programming assumed Functional design first

Lecture 1: Kotlin Foundations

Thirteen small readings on running Kotlin, imports, tests, values, expressions, Strings, math, programming foundations, and an optional image library.

9 necessary readings + 4 optional readings

Lecture 2: Functions, Tests, Helpers

Turn repeated calculations into named functions with signatures, examples, and helper functions.

5 necessary readings + 2 optional readings

Lectures 3-4: Choices and Product Data

Represent small sets of options with enums and combine fields with data classes.

5 necessary readings + 4 optional readings

Lecture 5: Conditions and Nested Data

Write multi-branch decisions and follow fields inside fields.

4 necessary readings + 2 optional readings

Lectures 6-7: Sum Types

Use sealed interfaces for data that comes in several shapes, then consume and produce that data.

4 necessary readings + 3 optional readings

Lectures 8-9: Recursion and Lists

Process recursive lists by handling the empty case and the node case.

4 necessary readings + 2 optional readings

Lecture 10: List Helpers and Domain Shifting

Break list problems into smaller functions before trying to calculate the final answer.

3 necessary readings + 2 optional readings

Lectures 11-13: Built-in Lists

Use Kotlin's immutable List type with map, filter, any, all, fold, and reduce.

6 necessary readings + 2 optional readings

Lecture 13 Challenge: Lambdas as Inputs

Pass small functions into larger functions to update and query data.

4 necessary readings + 2 optional readings

Lecture 14: Binary Trees

Write recursive functions over trees with two recursive subparts.

4 necessary readings + 2 optional readings

Lectures 15-16: Binary Search Trees

Use sorted-tree invariants to search, insert, and count without visiting every branch.

4 necessary readings + 2 optional readings

Lectures 17-18: Arbitrary-Arity Trees

Represent hierarchies where each node can have any number of children.

4 necessary readings + 2 optional readings

Lectures 19-20: Search Paths and Accumulators

Search trees for answers, build paths, and carry information down the recursion.

4 necessary readings + 2 optional readings

Lectures 21-23: Mutation and Loops

Understand when variables, lists, and objects can change over time.

6 necessary readings + 2 optional readings

Lectures 24-25: Graphs and Cycles

Traverse linked data with cycles using visited sets and worklists.

6 necessary readings + 2 optional readings

Extra: Graph Matrices and Loops

Represent graph edges in a grid and use nested loops to inspect the matrix.

5 necessary readings + 2 optional readings
