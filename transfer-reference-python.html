01 / Tools & files

Make a file. Run it. Inspect it.

PyCharm is the JetBrains Python IDE closest to the IntelliJ workflow used in the course. A Python interpreter runs your code.

A starting file and an entry point

Kotlin · hello.kt
fun main() {
    val name = "Gompei"
    println("Hello, $name!")
}
Python · hello.py
def main() -> None:
    name = "Gompei"
    print(f"Hello, {name}!")

if __name__ == "__main__":
    main()

Kotlin uses .kt; Python uses .py. Python does not call a function just because it is named main. The guard above calls it when the file runs as the main program, but not when another file imports it. Both print a line ending.

A short script and a library import

Kotlin
import kotlin.math.sqrt

fun main() {
    // Display the square root.
    println(sqrt(81.0)) // 9.0
}
Python
from math import sqrt

# Top-level statements run in order.
print(sqrt(81.0))  # 9.0

Python permits statements directly in a file. Importing that file executes its top-level statements the first time, so use the main guard for demonstrations and tests you do not want run during import. Use # for comments.

  1. Create: in PyCharm, create a Python project with a Python 3.10+ interpreter and a virtual environment, then add a Python file such as hello.py. The environment keeps project dependencies separate.
  2. Run: use the file’s Run command. In a terminal, use python hello.py; depending on your installation, the command may be python3 hello.py or, on Windows, py hello.py.
  3. Debug: click the gutter beside a line to set a breakpoint, then choose Debug. Inspect variables; use Step Over for the next line, Step Into to enter a call, and Resume to continue.
  4. Read errors: the last line of a traceback names the error; the frames above it identify the files and lines that led there. A syntax or indentation error must be fixed before that code can run.

No extra packages for this guide. math, dataclasses, enum, typing, and functools come with Python. An import makes a library name available; it does not install a package.

02 / Names & scope

Assignment needs no keyword

Python uses indentation for blocks, but a block does not necessarily introduce a scope.

Binding a name and changing its value

Kotlin
val x = 3
var count: Int = 0
count = count + 1
// x = 4 would be a compile error.
Python
x = 3
count: int = 0
count = count + 1
x = 4  # Rebinding is allowed.

There is no ordinary Python val declaration. An assignment binds a name to a value; a later assignment can rebind it. An annotation such as count: int documents the intended type for readers and checking tools. It does not enforce the type at runtime.

if and for do not create Python local scopes

Kotlin
val ready = true
val x = if (ready) {
    val chosen = 3
    chosen
} else {
    4
}
println(x) // 3
// chosen is out of scope here.
Python
ready = True
if ready:
    x = 3
else:
    x = 4
print(x)  # 3; same surrounding scope

for item in [10, 20]:
    last = item
print(item, last)  # 20 20

In Kotlin, a local declaration is available from its declaration through the enclosing block. In Python, if, for, and while blocks share the surrounding scope. Their assignments remain available afterward if those assignments ran. An empty loop or an unchosen branch might leave a name unbound.

Function calls have their own local names

Kotlin
fun nextCount(count: Int): Int {
    val next = count + 1
    return next
}
// next belongs to the function.
Python
def next_count(count: int) -> int:
    next_value = count + 1
    return next_value

# next_value belongs to the function.

Indentation is syntax. Use four spaces per level. A colon starts a function or control-flow body; indentation groups its statements. Function assignments are normally local. Prefer parameters and returned results to rebinding global names. Comprehension iteration variables also have their own scope (sheet 10).

03 / Primitive values

Numbers and Boolean expressions

Int becomes int, Double becomes float, and Boolean becomes bool.

Arithmetic, conversions, and division

Kotlin
import kotlin.math.pow

val sum = 7 + 2       // 9
val difference = 7 - 2 // 5
val product = 7 * 2   // 14
val quotient = 7 / 2  // 3
val decimal = 7.0 / 2 // 3.5
val remainder = 7 % 2 // 1
val square = 3.0.pow(2) // 9.0
val converted = 7.toDouble() // 7.0
val parsed = "42".toInt()   // 42
val text = 42.toString()    // "42"
Python
total = 7 + 2        # 9
difference = 7 - 2   # 5
product = 7 * 2      # 14
quotient = 7 // 2    # 3
decimal = 7 / 2      # 3.5
remainder = 7 % 2    # 1
square = 3 ** 2      # 9 (int)
converted = float(7) # 7.0
parsed = int("42")   # 42
text = str(42)       # "42"

Comparisons and short-circuit logic

Kotlin
val age = 20
val member = false
val adult = age >= 18
val offer = adult && !member // true
val eligible = adult || member
val teen = age >= 13 && age < 20
val different = age != 21
Python
age = 20
member = False
adult = age >= 18
offer = adult and not member  # True
eligible = adult or member
teen = 13 <= age < 20
different = age != 21

==, !=, <, <=, >, and >= compare values in both languages. Python spells the constants True and False. and and or skip the second operand when the first decides the result.

Truthiness is broader than Boolean values. Python treats 0, "", [], and None as false in conditions. Also, and and or return an operand: "" or "guest" gives "guest". Use explicit comparisons when that distinction matters.

04 / Text & optional values

Strings, equality, and None

Python’s str is immutable. Single and double quotes both create strings; there is no separate character type.

Reading and building text

Kotlin
val name = "Gompei"
name.length              // 6
name[0]                  // 'G' (Char)
name.substring(0, 3)     // "Gom"
name.lowercase()         // "gompei"
name.startsWith("Gom")   // true
name.contains("pei")     // true
"  hi  ".trim()          // "hi"
"red,blue".split(",")    // [red, blue]
"Hi, " + name            // "Hi, Gompei"
"$name has ${name.length} letters"
Python
name = "Gompei"
len(name)                # 6
name[0]                  # "G" (str)
name[0:3]                # "Gom"
name.lower()             # "gompei"
name.startswith("Gom")   # True
"pei" in name            # True
"  hi  ".strip()          # "hi"
"red,blue".split(",")    # ["red", "blue"]
"Hi, " + name            # "Hi, Gompei"
f"{name} has {len(name)} letters"

Both examples select from index 0 up to, but not including, 3. Python also permits name[-1] for the last character and name[:3] for the first three. A slice tolerates bounds beyond the string; a single out-of-range index raises IndexError. Kotlin’s substring checks its bounds.

Compare values; handle a missing value explicitly

Kotlin
val same = "cat" == "cat" // true
val nickname: String? = null
val label = nickname ?: "guest"
val size = nickname?.length
// label is "guest"; size is null.

if (nickname != null) {
    println(nickname.length)
}
Python
same = "cat" == "cat"  # True
nickname: str | None = None
label = (
    nickname if nickname is not None
    else "guest"
)
size = (
    len(nickname) if nickname is not None
    else None
)
if nickname is not None:
    print(len(nickname))

Python has no direct ?. or ?: operator. str | None documents a string-or-missing value. Test for None with is None or is not None. Accessing an absent value without checking can fail at runtime.

Two easy traps: use == for string contents, not is (object identity). Also, nickname or "guest" replaces an empty string as well as None; it is not the same as Kotlin’s null-only Elvis operator.

Official references: String operations Identity comparisons Union annotations

05 / Decisions

Choose a branch or a value

Use if / elif / else for conditions. Use match / case for selected value or shape patterns.

Two choices: if as an expression

Kotlin
val age = 20
val price = if (age < 18) 5 else 10
Python
age = 20
price = 5 if age < 18 else 10

Several conditions: when without a subject

Kotlin
fun label(score: Int): String {
    return when {
        score >= 90 -> "high"
        score >= 60 -> "passing"
        else -> "retry"
    }
}
Python
def label(score: int) -> str:
    if score >= 90:
        return "high"
    elif score >= 60:
        return "passing"
    else:
        return "retry"

Both choose the first satisfied condition. Python’s statement form does not produce a value: assign a result in each branch or return from a function. The final expression on a branch is not automatically returned.

Named choices: enum and value matching

Kotlin
enum class Signal { STOP, GO }

fun action(signal: Signal): String {
    return when (signal) {
        Signal.STOP -> "wait"
        Signal.GO -> "walk"
    }
}
Python
from enum import Enum

class Signal(Enum):
    STOP = "stop"
    GO = "go"

def action(signal: Signal) -> str:
    match signal:
        case Signal.STOP:
            return "wait"
        case Signal.GO:
            return "walk"
        case _:
            raise ValueError("Unknown signal")

Python match requires 3.10+. Patterns can also be literals such as case "stop":; case _: is a catch-all. It does not fall through to later cases. Python does not require exhaustive cases at runtime, so include a fallback when unmatched input would be a bug.

Pattern names matter. Keep the qualified name Signal.STOP. A bare case STOP: captures the subject in a variable named STOP; it does not compare to a constant. For arbitrary Boolean tests, use if / elif.

Official references: if & match Enum

06 / Design & tests

Keep the function design recipe

Purpose → signature and stub → examples → input inventory and helpers → implementation → tests.

State the purpose and type promise; start with a stub

Kotlin
/** Computes the price for count tickets. */
fun ticketCost(
    count: Int, discounted: Boolean
): Int {
    return 0 // temporary stub
}
Python
def ticket_cost(
    count: int, discounted: bool
) -> int:
    """Compute the price for count tickets."""
    return 0  # temporary stub

Python uses def, name: type for parameters, and -> type for the result. A first string in the body is a docstring. Python convention uses snake_case for functions and variables. Annotations are optional and are not runtime checks.

Implement with a local subcomputation

Kotlin · replace the stub body
fun ticketCost(
    count: Int, discounted: Boolean
): Int {
    val unitPrice = if (discounted) 5 else 10
    return count * unitPrice
}
val cost = ticketCost(
    count = 3, discounted = true
) // 15
Python · replace the stub body
def ticket_cost(
    count: int, discounted: bool
) -> int:
    """Compute the price for count tickets."""
    unit_price = 5 if discounted else 10
    return count * unit_price

cost = ticket_cost(
    count=3, discounted=True
)  # 15

return ends the call and supplies its result. Falling off a Python function’s end (or using bare return) returns None, even if its annotation promises int. For a function that only prints, annotate -> None instead of Kotlin’s Unit.

Turn examples into tests, without a test class

Kotlin · with the implemented function
import io.kotest.matchers.shouldBe

fun main() {
    ticketCost(0, false) shouldBe 0
    ticketCost(3, false) shouldBe 30
    ticketCost(3, true) shouldBe 15
}
Python · with the implemented function
def test_ticket_cost() -> None:
    assert ticket_cost(0, False) == 0
    assert ticket_cost(3, False) == 30
    assert ticket_cost(3, True) == 15

if __name__ == "__main__":
    test_ticket_cost()
    print("Tests passed")

assert raises AssertionError when its condition is false; a passing assertion is silent. Run the file to call these tests. Merely defining a test_... function does not execute it. Test boundaries and each branch; the nonzero examples should fail with the stub.

Testing details: for approximate decimal results, use from math import isclose and assert isclose(0.1 + 0.2, 0.3). Run normally: Python’s -O optimization removes assertions. Use explicit checks and exceptions for required input validation.

Official references: Functions assert isclose

07 / Compound data

Data classes carry named fields

A Python dataclass supplies a constructor and field-based equality. Use it as a record; functions can stay outside the class.

Define, construct, and select

Kotlin
data class Book(
    val title: String,
    val pages: Int
)

val book = Book(title = "Field Guide", pages = 80)
val title = book.title
val same = book == Book("Field Guide", 80)
// true
Python
from dataclasses import dataclass

@dataclass(frozen=True)
class Book:
    title: str
    pages: int

book = Book(title="Field Guide", pages=80)
title = book.title
same = book == Book("Field Guide", 80)
# True

The @dataclass decorator generates record behavior from the annotated fields. frozen=True rejects ordinary field reassignment, resembling Kotlin val fields. Without it, fields can be reassigned. Annotations do not check the constructor’s argument types at runtime.

Produce a changed copy and consume nested data

Kotlin · reuses Book above
val book = Book("Field Guide", 80)
val longer = book.copy(pages = 96)
// book.pages remains 80.

data class Loan(
    val book: Book,
    val borrower: String
)

fun loanLabel(loan: Loan): String {
    return "${loan.borrower}: ${loan.book.title}"
}

val loan = Loan(book, "Sam")
println(loanLabel(loan))
// Sam: Field Guide
Python · reuses Book above
from dataclasses import replace

book = Book("Field Guide", 80)
longer = replace(book, pages=96)
# book.pages remains 80.

@dataclass(frozen=True)
class Loan:
    book: Book
    borrower: str

def loan_label(loan: Loan) -> str:
    return f"{loan.borrower}: {loan.book.title}"

loan = Loan(book, "Sam")
print(loan_label(loan))
# Sam: Field Guide

Named arguments become Python keyword arguments. Dot selection works through nested records in both languages. Python dataclass equality compares fields when the two objects have the same class; is would instead ask whether they are the very same object.

Copies and freezing are shallow. Neither a Kotlin val field nor a frozen Python dataclass makes a contained mutable list immutable. Kotlin copy and Python replace reuse unchanged field values; they do not recursively copy everything inside.

Official references: dataclass, frozen records & replace Kotlin copies

08 / Sum data

Separate variants, then check the case

Use dataclasses for the alternatives and match / case to distinguish them and extract their fields. Python's is keyword means something different than Kotlin's.

A result is either a success or a failure

Kotlin
sealed interface Result
data class Success(val message: String) : Result
data class Failure(val reason: String) : Result

fun describe(result: Result): String {
    return when (result) {
        is Success -> result.message
        is Failure -> "Error: ${result.reason}"
    }
}

val ok: Result = Success("Saved")
val bad: Result = Failure("No space")
println(describe(ok))  // Saved
println(describe(bad)) // Error: No space
Python
from dataclasses import dataclass

@dataclass(frozen=True)
class Success:
    message: str

@dataclass(frozen=True)
class Failure:
    reason: str

Result = Success | Failure

def describe(result: Result) -> str:
    match result:
        case Success(message):
            return message
        case Failure(reason):
            return f"Error: {reason}"
        case _:
            raise TypeError("Unknown result")

ok: Result = Success("Saved")
bad: Result = Failure("No space")
print(describe(ok))   # Saved
print(describe(bad))  # Error: No space

Success | Failure is a union annotation for tools and readers. It does not close a family of variants like a sealed interface, nor prevent other values being passed at runtime. The class pattern Success(message) checks the variant and binds its first field to the local name message; Failure(reason) binds its first field to reason. These dataclasses support positional patterns in field declaration order; the local names need not match the field names. Python does not enforce exhaustive matching at runtime, so case _: rejects unexpected values.

Duck typing is a different choice

Kotlin · reuses Success
fun messageText(value: Success): String {
    return value.message
}

println(messageText(Success("Saved")))
Python · reuses Success
def message_text(value) -> str:
    return value.message

print(message_text(Success("Saved")))
# Any object with a usable .message works.

Duck typing means using an object’s supported fields or operations without first checking its class. The class patterns above do check the class. Here, a Failure has no message, so passing it to message_text raises AttributeError. Use explicit variant matching when the alternatives require different work.

Keep the data-driven template. Write one branch per variant, select only that variant’s fields, and give each branch a result. The classes above are plain data records; they need no custom methods or shared base class.

Official references: match & class patterns Union types Duck typing

09 / Collections

List<T> becomes list[T]

Python’s everyday array-like collection is list: an ordered, resizable, mutable sequence. It is not the specialized array module.

Construct, index, slice, and combine

Kotlin
val scores: List<Int> = listOf(10, 20, 30)
val empty: List<Int> = emptyList()
scores.size               // 3
scores[0]                 // 10
scores.last()             // 30
scores.take(2)            // [10, 20]
scores.drop(1)            // [20, 30]
20 in scores              // true
scores.isEmpty()          // false
val more = scores + listOf(40)
// scores remains [10, 20, 30].
Python
scores: list[int] = [10, 20, 30]
empty: list[int] = []
len(scores)               # 3
scores[0]                 # 10
scores[-1]                # 30
scores[:2]                # [10, 20]
scores[1:]                # [20, 30]
20 in scores              # True
not scores                # False
more = scores + [40]
# scores remains [10, 20, 30].

Both use index 0 for the first element. Python slices use an exclusive end. + creates a new list; append changes an existing one. Python can store mixed types in one list, but list[int] records your intended element type without enforcing it at runtime.

Find, sort, and compare

Kotlin
val scores = listOf(30, 10, 20)
val found = scores.find { it > 15 }
// 30; null if nothing matches
val ordered = scores.sorted()
// [10, 20, 30]; scores is unchanged
val same = listOf(1, 2) == listOf(1, 2)
// true
Python
scores = [30, 10, 20]
found = next((x for x in scores if x > 15), None)
# 30; None if nothing matches
ordered = sorted(scores)
# [10, 20, 30]; scores is unchanged
same = [1, 2] == [1, 2]
# True

The parenthesized generator supplies candidates to next as needed; None is the default when none match. This works as an absence marker here because the elements are integers. List == compares elements in order.

Read-only and mutable are different promises. Kotlin’s List<T> exposes read-only operations (a backing object can still be mutable). Python list[T] allows updates. To preserve the course’s functional style, produce new lists and avoid mutating inputs. An immutable sequence option is a tuple, for example (10, 20, 30).

10 / Higher-order operations

Transform, select, and summarize

For the comparisons below, use val nums = listOf(1, 2, 3, 4) in Kotlin and nums = [1, 2, 3, 4] in Python.

map and filter: functions or comprehensions

Kotlin · uses nums above
val squares = nums.map { n -> n * n }
// [1, 4, 9, 16]
val evens = nums.filter { it % 2 == 0 }
// [2, 4]
val evenSquares = nums
    .filter { it % 2 == 0 }
    .map { it * it }
// [4, 16]
Python · uses nums above
squares = list(map(lambda n: n * n, nums))
evens = list(filter(lambda n: n % 2 == 0, nums))

# Usually clearer: list comprehensions.
squares = [n * n for n in nums]
evens = [n for n in nums if n % 2 == 0]
even_squares = [n * n for n in nums if n % 2 == 0]
# [1, 4, 9, 16]; [2, 4]; [4, 16]

A comprehension builds a new list; its loop variable does not escape into the surrounding scope. Python map and filter return lazy iterators, consumed as you traverse them. Wrap them in list(...) for stored results like Kotlin’s list operations.

any, all, and fold

Kotlin · uses nums above
val hasEven = nums.any { it % 2 == 0 }
val allPositive = nums.all { it > 0 }
val total = nums.fold(0) { acc, n -> acc + n }
val product = nums.fold(1) { acc, n -> acc * n }
// true, true, 10, 24
val simplerTotal = nums.sum()
Python · uses nums above
from functools import reduce

has_even = any(n % 2 == 0 for n in nums)
all_positive = all(n > 0 for n in nums)
total = reduce(lambda acc, n: acc + n, nums, 0)
product = reduce(lambda acc, n: acc * n, nums, 1)
# True, True, 10, 24
simpler_total = sum(nums)

any and all short-circuit over generated Boolean values. On an empty collection, any is false and all is true in both languages. reduce(function, items, initial) matches a left fold: accumulator first, element second. Empty input returns the initial value; omitting it on empty input raises an error.

Function values, references, and lambda syntax

Kotlin
fun double(n: Int): Int = n * 2
val operation: (Int) -> Int = ::double
val triple: (Int) -> Int = { n -> n * 3 }
val answer = operation(4) // 8
val results = listOf(1, 2).map(::double)
Python
from typing import Callable

def double(n: int) -> int:
    return n * 2

operation: Callable[[int], int] = double
triple = lambda n: n * 3
answer = operation(4)  # 8
results = list(map(double, [1, 2]))

A name passes the function; parentheses call it. Python uses double where Kotlin uses ::double. A Python lambda contains exactly one expression, whose value is returned. Use def for multiple statements; there is no implicit it.

Official references: map, filter, any & all reduce Comprehensions

11 / State

Rebinding versus changing an object

Assignment changes what a name refers to. Mutation changes the contents of an existing object, visible through every name referring to it.

Update numbers, list elements, and list size

Kotlin
var count = 1
count += 2
count++ // now 4

val scores = mutableListOf(10, 20)
scores[0] = 11
scores.add(30)
scores.addAll(listOf(40, 50))
val removed = scores.removeAt(1)
// removed is 20
// scores is [11, 30, 40, 50]
Python
count = 1
count += 2
count += 1  # now 4; no ++ operator

scores = [10, 20]
scores[0] = 11
scores.append(30)
scores.extend([40, 50])
removed = scores.pop(1)
# removed is 20
# scores is [11, 30, 40, 50]

Python append, extend, and sort mutate a list and return None. Do not write scores = scores.append(30): that loses the list binding. scores.sort() mutates; sorted(scores) returns a new list.

Aliasing, shallow copies, and mutable fields

Kotlin
val original = mutableListOf(1, 2)
val alias = original
val separate = original.toMutableList()
alias.add(3)
// original: [1, 2, 3]; separate: [1, 2]

data class Counter(var value: Int)
val counter = Counter(0)
counter.value += 1
Python
from dataclasses import dataclass

original = [1, 2]
alias = original
separate = original.copy()
alias.append(3)
# original: [1, 2, 3]; separate: [1, 2]

@dataclass
class Counter:
    value: int

counter = Counter(0)
counter.value += 1

Assignment does not copy an object. list.copy() makes a new outer list but reuses its elements. A function parameter can also refer to a caller’s list: appending through that parameter changes the caller’s list; assigning a different list to the parameter only rebinds the local name.

+= depends on the value. For a Python integer it computes a new value and rebinds the name. For a list, items += [x] extends the existing list, so aliases observe it. items = items + [x] instead binds the name to a new list.

12 / Repetition & input

Loop over values or a range

Python for visits an iterable’s values; while repeats while a condition is truthy.

Elements, indices, and a running total

Kotlin
val scores = listOf(10, 20, 30)
var total = 0
for (score in scores) {
    total += score
}
for ((index, score) in scores.withIndex()) {
    println("$index: $score")
}
// total is 60.
Python
scores = [10, 20, 30]
total = 0
for score in scores:
    total += score

for index, score in enumerate(scores):
    print(f"{index}: {score}")
# total is 60.

Range boundaries and steps

Kotlin
for (i in 1..3) println(i)
// 1, 2, 3
for (i in 0 until 3) println(i)
// 0, 1, 2
for (i in 1..7 step 2) println(i)
// 1, 3, 5, 7
for (i in 3 downTo 1) println(i)
// 3, 2, 1
Python
for i in range(1, 4):
    print(i)  # 1, 2, 3
for i in range(3):
    print(i)  # 0, 1, 2
for i in range(1, 8, 2):
    print(i)  # 1, 3, 5, 7
for i in range(3, 0, -1):
    print(i)  # 3, 2, 1

range(start, stop, step) always excludes stop, including when counting downward. Defaults are start 0 and step 1. A range is an iterable sequence, not a prebuilt list; use list(range(...)) when you need one.

Read until a sentinel; skip and stop

Kotlin
while (true) {
    print("Word (quit to stop): ")
    val word = readln()
    if (word == "quit") break
    if (word.isEmpty()) continue
    println(word.uppercase())
}
// For numeric input:
// val age = readln().toInt()
Python
while True:
    word = input("Word (quit to stop): ")
    if word == "quit":
        break
    if word == "":
        continue
    print(word.upper())

# For numeric input:
# age = int(input("Age: "))

input returns text without the trailing newline; int(...) converts integer text and raises ValueError for invalid text. break exits the nearest loop; continue skips to its next iteration.

Choose the clearest form. Use a comprehension to build a new list (sheet 10), a collection summary such as sum for a total, and a loop for repeated effects. Avoid adding or removing elements from the same list you are traversing; build a filtered list instead.
