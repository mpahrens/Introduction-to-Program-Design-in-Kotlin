Values Have Types

A type tells Kotlin what kind of value it is working with and which operations make sense for that value.

Necessary 2-3 minutes Vocabulary: value, type, Boolean

Four Types to Recognize

A value is a piece of data a program uses or computes. Every value has a type, a category that tells Kotlin what the value means and what can be done with it.

12          // Int
12.5        // Double
"twelve"    // String
true        // Boolean

An Int is a whole number. A Double is a number that can have a decimal part. A String is text enclosed in quotation marks. A Boolean is either true or false.

Appearance Matters

The values 12, 12.0, and "12" look related to a person, but Kotlin gives them different types. The decimal point makes 12.0 a Double. The quotation marks make "12" a String.

Types prevent nonsensical operations. Adding two numbers makes sense. Asking whether one number is smaller than another makes sense. Kotlin uses the types involved to decide whether an operation is allowed and what kind of value it produces.

12 + 3       // produces the Int value 15
12 < 20      // produces the Boolean value true

Practice

  1. Name the type of 8, 8.0, "8.0", and false.
  2. What type of value does 10 > 4 produce?
  3. What one piece of punctuation distinguishes 6 from 6.0?
Check your answers

1. Int, Double, String, and Boolean.

2. It produces a Boolean.

3. The decimal point makes 6.0 a Double.
