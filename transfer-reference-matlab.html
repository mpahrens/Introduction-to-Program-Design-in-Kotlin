01 / Files, running & debugging

The MATLAB desktop is your IDE

Use the Editor for code, the Command Window for commands and output, and the Workspace panel to inspect variables.

A script can run directly

Kotlin
fun main() {
    val name = "Gompei"
    println("Hello, $name!")
}
MATLAB · script hello.m
name = "Gompei";
disp("Hello, " + name + "!");

% In the Command Window, run:
% hello

A plain code file ends in .m. A script runs its statements in order; no special main is required. disp displays a value and a newline. A semicolon suppresses automatic result display, but not an explicit disp call. Comments start with %.

Built-in functions and formatted output

Kotlin
import kotlin.math.sqrt

fun main() {
    println(sqrt(81.0)) // 9.0
    print("Ready")      // no newline
}
MATLAB · script
disp(sqrt(81));      % 9
fprintf("Ready");    % no newline
fprintf("\nScore: %.1f\n", 8.5);
% %.1f formats one decimal place.
  1. Create and run: choose New Script, save hello.m, and click Run. Keep it in the Current Folder or on the MATLAB search path. Typing hello in the Command Window also runs it.
  2. Debug: click beside an executable line number to set a breakpoint. Run, inspect variables, and use Step, Step In, and Continue. dbstop if error pauses on an error.
  3. Get help: use help sqrt for a short description, doc sqrt for documentation, or which sqrt to locate the implementation.

Files and libraries: these examples use base MATLAB, with no imports or extra toolboxes. Reusable function files are named after their first function. Avoid naming variables or files sum, length, or other functions you intend to call. Live scripts, commonly saved as .mlx, combine code and formatted notes.

02 / Variables & workspaces

Variables belong to a workspace

An assignment creates or updates a variable. MATLAB has no ordinary val declaration.

Assign and reassign

Kotlin
val x = 3
var count = 0
count += 1
// x = 4 would be a compile error.
MATLAB · script
x = 3;
count = 0;
count = count + 1;
x = 4;  % Reassignment is allowed.
class(x) % 'double'
whos x   % Show type, size, and storage.

Variables have no fixed declared type: the assigned value determines their type and size. Numeric literals such as 3 normally create double values. Reassigning x = "three" is permitted, but may break later numeric computations.

Conditional and loop blocks share the surrounding scope

Kotlin
val ready = true
val x = if (ready) {
    val chosen = 3
    chosen
} else {
    4
}
println(x)
// chosen is out of scope here.
MATLAB · script
ready = true;
if ready
    x = 3;
else
    x = 4;
end
disp(x); % 3; same workspace

for item = [10 20]
    last = item;
end
disp(last); % 20; still available

if, for, and while share the surrounding workspace. A variable exists afterward only if an assignment ran, or it already existed. MATLAB uses end to close these blocks; indentation is for readability.

02 / Variables & workspaces · continued

Functions have separate local variables

Save the MATLAB definition below in nextCount.m. Its input count, temporary variable increment, and output next all belong to the function’s own workspace.

Kotlin
fun nextCount(count: Int): Int {
    val increment = 1
    val next = count + increment
    return next
}
MATLAB · nextCount.m
function next = nextCount(count)
    increment = 1;
    next = count + increment;
end

Put this calling code in a separate script, demo_count.m, in the same folder. Run that script, or enter its statements in the Command Window. The call passes a value into the function and assigns the returned value to updated.

Kotlin · calls nextCount above
fun main() {
    val count = 3
    val next = 100
    val updated = nextCount(count)
    println(listOf(count, next, updated))
    // [3, 100, 4]
    // increment is not in scope here.
}
MATLAB · script demo_count.m
count = 3;
next = 100;
updated = nextCount(count);
disp([count next updated]); % [3 100 4]
% increment is not available here.

Inside the function: it can use its parameters and variables it creates, but cannot read unrelated variables from the calling script. Even though that script has a count, calling nextCount() without an argument will fail when the function tries to use its missing input. Reassigning a numeric parameter inside MATLAB changes only the local value.

Back in the caller: the function’s next becomes the value assigned to updated; it does not overwrite the caller’s separate next. The temporary increment is not exposed. If the caller already had its own increment, that variable would remain independent.

Scripts share; ordinary functions isolate. Scripts run in the caller’s workspace. Functions in their own files, and local functions at the end of scripts, have separate workspaces. Being in the same folder or script file does not grant access to the caller’s variables. Nested functions defined inside another function have different sharing rules; the examples here use ordinary functions.

03 / Numbers & Booleans

Numbers are arrays, even scalars

A scalar is a 1-by-1 array. Ordinary numeric literals are floating-point double values, even without a decimal point.

Arithmetic and integer-like calculations

Kotlin
val total = 7 + 2       // 9
val difference = 7 - 2  // 5
val product = 7 * 2     // 14
val quotient = 7 / 2    // 3
val decimal = 7.0 / 2   // 3.5
val remainder = -7 % 2 // -1
val truncated = (-3.8).toInt() // -3
MATLAB · script
total = 7 + 2;         % 9
difference = 7 - 2;    % 5
product = 7 * 2;       % 14
quotient = fix(7 / 2); % 3, still double
decimal = 7 / 2;       % 3.5
remainder = rem(-7, 2); % -1
truncated = fix(-3.8); % -3, still double
modulo = mod(-7, 2);   % 1

fix truncates toward zero; floor rounds down. rem matches the sign behavior of Kotlin’s integer %; mod can differ for negative inputs. Integer classes such as int32 also exist, but converting a fraction to an integer class rounds rather than simply truncating. A double cannot represent every arbitrarily large integer exactly.

Comparisons and scalar logic

Kotlin
val age = 20
val member = false
val eligible = age >= 18 && !member
val either = member || age >= 65
val different = age != 21
val teen = age >= 13 && age < 20
MATLAB · script
age = 20;
member = false;
eligible = age >= 18 && ~member;
either = member || age >= 65;
different = age ~= 21;
teen = age >= 13 && age < 20;

Booleans have class logical and often display as 1 or 0. Use ~ for not and ~= for not equal. && and || require scalar conditions and short-circuit; & and | operate element by element. Do not chain comparisons as 13 <= age < 20.

Calculate separately for each element

Kotlin
val xs = listOf(2.0, 4.0)
val squares = xs.map { it * it }
val halves = xs.map { it / 2 }
// [4.0, 16.0]; [1.0, 2.0]
MATLAB · script
xs = [2 4];
squares = xs.^2;
halves = xs./2;
% [4 16]; [1 2]

The dots matter. Use .*, ./, and .^ for element-wise work. Without dots, these operators have linear-algebra meanings for nonscalar arrays. Corresponding-element calculations need matching shapes; compatible unequal shapes can expand the result.

04 / Strings & conversions

Use double quotes for string values

MATLAB distinguishes a string scalar such as "Gompei" from a character vector such as 'Gompei'.

Read and build text

Kotlin
val name = "Gompei"
name.length              // 6
name.substring(0, 3)     // "Gom"
name.lowercase()         // "gompei"
name.startsWith("Gom")   // true
name.contains("pei")     // true
"  hi  ".trim()          // "hi"
"Hi, " + name            // "Hi, Gompei"
"$name has ${name.length} letters"
MATLAB · script
name = "Gompei";
strlength(name)           % 6
extractBetween(name, 1, 3) % "Gom"
lower(name)               % "gompei"
startsWith(name, "Gom")   % true
contains(name, "pei")     % true
strtrim("  hi  ")         % "hi"
"Hi, " + name             % "Hi, Gompei"
name + " has " + string(strlength(name)) ...
    + " letters"

extractBetween with numeric positions includes both endpoints and counts from 1. ... continues a statement on the next line. strlength counts characters in each string; numel(name) is 1 because name contains one string.

Character access, equality, and conversions

Kotlin
val name = "Gompei"
val first = name[0]       // 'G'
val same = name == "Gompei"
val n = "42".toDouble()   // 42.0
val text = 42.toString()  // "42"
val words = listOf("red", "blue")
val word = words[0]       // "red"
MATLAB · script
name = "Gompei";
chars = char(name);
first = chars(1);         % 'G'
same = name == "Gompei";  % true
n = str2double("42");     % 42
text = string(42);        % "42"
words = ["red" "blue"];
word = words(1);          % "red"

name(1) selects the first string, not its first character. Convert to a character vector and index it, or use text extraction. == compares string values; for character vectors use strcmp to compare whole texts.

Conversions and absent data: str2double("hello") produces NaN; check with isnan, not == NaN. There is no single general-purpose equivalent of Kotlin’s null. [] is an empty array, "" is an empty-text string, and a missing string is checked with ismissing. Document the representation your function uses.

05 / if, when & switch

Choose a branch, then assign a result

Use if / elseif / else / end for conditions and switch / case / otherwise / end for value choices.

Two choices and several conditions

Kotlin
val age = 20
val price = if (age < 18) 5 else 10

val score = 75
val label = when {
    score >= 90 -> "high"
    score >= 60 -> "passing"
    else -> "retry"
}
MATLAB · script
age = 20;
if age < 18
    price = 5;
else
    price = 10;
end

score = 75;
if score >= 90
    label = "high";
elseif score >= 60
    label = "passing";
else
    label = "retry";
end

Both choose the first satisfied condition. MATLAB’s if is a statement, not an expression: assign a result inside each branch. There is no direct ternary if expression. Prefer scalar logical conditions; a nonscalar condition is true only when it is nonempty and all its elements are nonzero.

when with a subject becomes switch

Kotlin
val signal = "go"
val action = when (signal) {
    "stop" -> "wait"
    "go" -> "walk"
    else -> error("Unknown signal")
}
MATLAB · script
signal = "go";
switch signal
    case "stop"
        action = "wait";
    case "go"
        action = "walk";
    otherwise
        error("Unknown signal");
end

switch stops after the matching case body; there is no fall-through or need for break. Use otherwise for unexpected values. These string labels are a convention, not an enum type restricting possible inputs.

Value cases are not predicate cases. For tests such as score >= 90, use if / elseif. A case expression is compared with the switch value; it does not mean “run this case if this condition is true.” MATLAB does not require exhaustive cases.

06 / Function design & testing

Name the output in the signature

Keep the recipe: purpose, signature and stub, examples, input inventory, implementation, and tests.

Define and implement a function

Kotlin
/** Computes the price for count tickets. */
fun ticketCost(
    count: Int, discounted: Boolean
): Int {
    val unitPrice = if (discounted) 5 else 10
    return count * unitPrice
}
val cost = ticketCost(3, true) // 15
MATLAB · ticketCost.m
function cost = ticketCost(count, discounted)
% Compute the price for count tickets.
    if discounted
        unitPrice = 5;
    else
        unitPrice = 10;
    end
    cost = count * unitPrice;
end

% From a script or the Command Window:
% cost = ticketCost(3, true); % 15

The output cost appears before = in the signature. Assign it before finishing. MATLAB’s return only exits early; it takes no result expression. A stub could assign cost = 0;. A function with no output omits cost = from its signature.

Optional runtime input validation

Kotlin
// Inside ticketCost:
// The signature requires Int and Boolean.
require(count >= 0)
// Then compute the ticket cost.
MATLAB · insert before the function body
arguments
    count (1,1) double ...
        {mustBeInteger, mustBeNonnegative}
    discounted (1,1) logical
end
% Then compute the ticket cost.

An arguments block follows the function declaration and help comments, before executable statements. (1,1) requires a scalar. Class and size declarations can convert compatible inputs. These are runtime requirements, not Kotlin-style compile-time types.

Test examples with assert

Kotlin
// With Kotest shouldBe imported:
ticketCost(0, false) shouldBe 0
ticketCost(3, false) shouldBe 30
ticketCost(3, true) shouldBe 15
listOf(1, 2) shouldBe listOf(1, 2)
MATLAB · script test_ticketCost.m
assert(ticketCost(0, false) == 0);
assert(ticketCost(3, false) == 30);
assert(ticketCost(3, true) == 15);
assert(isequal([1 2], [1 2]));
disp("Tests passed");

Run the script with ticketCost.m in the Current Folder or on the path. Passing assertions are silent; failures raise errors. Use isequal for whole arrays or structs: array == produces per-element results. For decimals, use an appropriate tolerance, such as assert(abs((0.1 + 0.2) - 0.3) < 1e-12).

File organization: name a reusable function file after its first function. Helpers used only within a script can be local functions placed after all script statements. This placement also works before R2024a, when it was required. Local functions are visible only within their file.

MathWorks references: Functions Validation assert Local functions

07 / Compound data with structs

Use a struct for named fields

A struct groups fields into one value. It does not declare a new type like a Kotlin data class.

A constructor helper, construction, and field selection

Kotlin
data class Book(
    val title: String,
    val pages: Int
)

val book = Book("Field Guide", 80)
val title = book.title
val same = book == Book("Field Guide", 80)
// true
MATLAB · makeBook.m
function book = makeBook(title, pages)
    book = struct("title", title, ...
                  "pages", pages);
end

% In a script or the Command Window:
% book = makeBook("Field Guide", 80);
% title = book.title;
% same = isequal(book, ...
%     makeBook("Field Guide", 80)); % true

struct takes alternating field names and values. Dot notation selects fields. A constructor helper provides one place to document and validate the representation. These values still have class struct; there is no automatically introduced Book type.

Produce a changed copy and access nested fields

Kotlin
// Reuses Book above.
val book = Book("Field Guide", 80)
val longer = book.copy(pages = 96)

data class Loan(
    val book: Book, val borrower: String
)
val loan = Loan(book, "Sam")
val title = loan.book.title
// book.pages: 80; longer.pages: 96
MATLAB · script; uses makeBook.m
book = makeBook("Field Guide", 80);
longer = book;
longer.pages = 96;

loan = struct("book", book, ...
              "borrower", "Sam");
title = loan.book.title;
% book.pages: 80; longer.pages: 96

Ordinary structs have value semantics: updating longer.pages does not change book.pages. Unlike Kotlin val fields, struct fields can be reassigned or added freely. Names and field types are conventions unless your functions validate them.

Pass data in, return changed data out. A helper that updates a struct should return the updated struct; assign that result in the caller. Updating an ordinary struct parameter does not mutate the caller’s variable. The course’s “produce new data” style fits naturally.

08 / Sum types with tags

Mark the variant with a tag

Represent each alternative as a struct with a kind field. Use switch on that tag to select the appropriate fields.

A result is either a success or a failure

Kotlin
sealed interface Result
data class Success(val message: String) : Result
data class Failure(val reason: String) : Result

fun describe(result: Result): String {
    return when (result) {
        is Success -> result.message
        is Failure -> "Error: ${result.reason}"
    }
}

val ok: Result = Success("Saved")
val bad: Result = Failure("No space")
println(describe(ok))  // Saved
println(describe(bad)) // Error: No space
MATLAB · script demo_result.m
ok = struct("kind", "success", ...
            "message", "Saved");
bad = struct("kind", "failure", ...
             "reason", "No space");
disp(describe(ok));  % Saved
disp(describe(bad)); % Error: No space

function text = describe(result)
    switch result.kind
        case "success"
            text = result.message;
        case "failure"
            text = "Error: " + result.reason;
        otherwise
            error("Unknown result kind");
    end
end

This is a tagged representation by convention, not a sealed type. MATLAB does not prove that all variants are handled or that a success carries a message. An unknown tag reaches otherwise; a missing field causes a field-access error. Constructor helpers and tests can enforce the intended representation.

A function can depend only on a field

Kotlin
// Reuses Success above.
fun messageText(value: Success): String {
    return value.message
}
MATLAB · messageText.m
function text = messageText(value)
    text = value.message;
end

The MATLAB function accepts any struct with a suitable message field. This is a form of duck typing: the supported field matters rather than a declared record class. Passing the failure struct above fails because it has no message.

A class test does not separate these variants. Both are structs, so isstruct or isa(value, "struct") cannot distinguish success from failure. Match the tag instead. MATLAB switch does not destructure a record or bind its fields as a pattern; select them with dot notation inside each case.

09 / Arrays, indexing & cells

Choose an array representation

Use numeric vectors for numbers, string arrays for text, and cell arrays for values of different types or sizes.

A list of numbers becomes a numeric vector

Kotlin
val scores = listOf(10, 20, 30)
scores.size          // 3
scores[0]            // 10
scores.last()        // 30
scores.take(2)       // [10, 20]
scores.drop(1)       // [20, 30]
20 in scores         // true
scores.isEmpty()     // false
val more = scores + listOf(40)
MATLAB · script
scores = [10 20 30]; % a row vector
numel(scores)        % 3
scores(1)            % 10
scores(end)          % 30
scores(1:2)          % [10 20]
scores(2:end)        % [20 30]
ismember(20, scores) % true
isempty(scores)      % false
more = [scores 40];  % concatenate

MATLAB indices start at 1 and use parentheses. Square brackets construct or concatenate arrays. 1:2 includes both endpoints; end in an index means the last position. Reading beyond the bounds is an error. numel counts all elements; length gives the largest dimension.

Mixed values use cells; braces extract the contents

Kotlin
val items: List<Any> =
    listOf("Gompei", 80)
val first = items[0] // "Gompei"
val oneItem = items.take(1)
// A list containing "Gompei".
MATLAB · script
items = {"Gompei", 80};
first = items{1};   % string "Gompei"
oneItem = items(1); % a 1-by-1 cell array

% Vectors have an orientation:
row = [10 20 30];      % 1-by-3
column = [10; 20; 30]; % 3-by-1

Parentheses select cells; braces retrieve their contents. Prefer numeric vectors for homogeneous numeric lists. Row and column orientation affect concatenation and element-wise operations, so keep shapes consistent when translating list operations.

Lookups need an absence convention. find(scores > 15, 1) returns the first matching index, or [] if none exists. Check isempty(index) before using that index to retrieve a value. Kotlin’s find instead returns the matching element or null.

MathWorks references: Indexing Cells find

10 / map, filter, any, all & fold

Use arrays and function handles

Start with Kotlin val nums = listOf(1, 2, 3, 4) or MATLAB nums = [1 2 3 4];.

map, lambdas, and filter

Kotlin
// Uses nums above.
val square = { n: Int -> n * n }
val squares = nums.map(square)
val evens = nums.filter { it % 2 == 0 }
val evenSquares = nums
    .filter { it % 2 == 0 }
    .map { it * it }
// [1, 4, 9, 16]; [2, 4]; [4, 16]
MATLAB · script
% Uses nums above.
square = @(n) n.^2;
squares = arrayfun(square, nums);
% Or use vectorized arithmetic:
squares = nums.^2;
evens = nums(mod(nums, 2) == 0);
evenSquares = evens.^2;
% [1 4 9 16]; [2 4]; [4 16]

@(n) expression creates an anonymous function. arrayfun applies a handle to each element; by default the results must be compatible scalars. Vectorized arithmetic is often simpler. A logical mask selects matching elements, serving the same purpose as Kotlin’s filter.

any, all, and common summaries

Kotlin
// Uses nums above.
val hasEven = nums.any { it % 2 == 0 }
val allPositive = nums.all { it > 0 }
val total = nums.sum()
val product = nums.fold(1) { acc, n -> acc * n }
// true, true, 10, 24
MATLAB · script
% Uses nums above.
hasEven = any(mod(nums, 2) == 0, "all");
allPositive = all(nums > 0, "all");
total = sum(nums);
product = prod(nums);
% true, true, 10, 24

"all" reduces across every element, regardless of shape. Empty input gives false for any and true for all. The predicate arrays are computed first; unlike Kotlin’s predicate calls, their evaluation does not stop at the first deciding element.

A general left fold can be a small helper

Kotlin
val nums = listOf(1, 2, 3, 4)
val total = nums.fold(0) { acc, n -> acc + n }
// 10

fun double(n: Int): Int = n * 2
val operation: (Int) -> Int = ::double
val answer = operation(4) // 8
MATLAB · script with local helper
nums = [1 2 3 4];
total = foldLeft(@(acc, n) acc + n, nums, 0);
operation = @(n) n * 2;
answer = operation(4); % 8

function acc = foldLeft(combine, xs, initial)
    acc = initial;
    for k = 1:numel(xs)
        acc = combine(acc, xs(k));
    end
end

Handles are function values. Use @myFunction for a named function, like ::myFunction in Kotlin. Anonymous functions contain one expression and capture current ordinary variable values when created. Use cellfun for cell contents. The fold helper preserves order and returns the initial value on empty input.

MathWorks references: arrayfun Anonymous functions any all

11 / Updates & value semantics

Updates change a variable’s value

MATLAB numeric arrays, strings, cells, and ordinary structs use value semantics, rather than Kotlin mutable-list aliasing.

Update numbers, elements, and array size

Kotlin
var count = 1
count += 2
count++ // 4

val scores = mutableListOf(10, 20)
scores[0] = 11
scores.add(30)
val removed = scores.removeAt(1)
// removed: 20; scores: [11, 30]
MATLAB · script
count = 1;
count = count + 2;
count = count + 1; % 4; no ++ or +=

scores = [10 20];
scores(1) = 11;
scores(end + 1) = 30;
removed = scores(2);
scores(2) = [];
% removed: 20; scores: [11 30]

Assigning [] to indexed positions deletes those elements. Writing just beyond the end grows an array. When the final size is known, preallocate with zeros instead of repeatedly growing the array in a loop.

Assignment does not create a shared mutable array

Kotlin
val original = mutableListOf(1, 2)
val alias = original
alias[0] = 99
// original is now [99, 2].

val separate = original.toMutableList()
separate[0] = 7
// original is still [99, 2].
MATLAB · script
original = [1 2];
separate = original;
separate(1) = 99;
% original is still [1 2].
% separate is [99 2].

book = struct("pages", 80);
revised = book;
revised.pages = 96;
% book.pages is still 80.

MATLAB may share storage internally until an update requires copying, but the observable behavior for these values is independent updates. A function that updates an ordinary array parameter must return the updated array if the caller is to receive it.

This rule is about the values used here. MATLAB also has handle objects with shared-reference behavior. A struct or cell containing a handle can refer to that shared object. Ordinary numeric arrays and the simple records in this guide do not have that behavior.

MathWorks references: Copy behavior Indexing Preallocation

12 / Loops, ranges & input

Repeat over indices or a range

A for loop visits a known sequence; a while loop repeats while a condition holds. Close each body with end.

Visit values and build a result

Kotlin
val scores = listOf(10, 20, 30)
var total = 0
for (score in scores) {
    total += score
}
val squares = scores.map { it * it }
// total: 60; squares: [100, 400, 900]
MATLAB · script
scores = [10 20 30];
total = 0;
squares = zeros(size(scores));
for k = 1:numel(scores)
    total = total + scores(k);
    squares(k) = scores(k).^2;
end
% total: 60; squares: [100 400 900]
% Simpler here: sum(scores), scores.^2

A MATLAB for value = array visits columns. A row vector yields one scalar at a time; a column vector yields the whole column in one iteration. The index loop above visits each element of either vector orientation.

Ranges include reachable endpoints

Kotlin
for (i in 1..3) println(i) // 1, 2, 3
for (i in 0 until 3) println(i) // 0, 1, 2
for (i in 1..7 step 2) println(i)
// 1, 3, 5, 7
for (i in 3 downTo 1) println(i)
// 3, 2, 1
MATLAB · script
for i = 1:3
    disp(i); % 1, 2, 3
end
% Other ranges:
% 0:2    gives 0, 1, 2
% 1:2:7  gives 1, 3, 5, 7
% 3:-1:1 gives 3, 2, 1

The order is start:step:stop, with step 1 if omitted. The stop value is included only if reached: 1:2:6 gives [1 3 5]. 3:1 is empty because its default step is positive.

Read text until a sentinel

Kotlin
while (true) {
    print("Word (quit to stop): ")
    val word = readln()
    if (word == "quit") break
    if (word.isEmpty()) continue
    println(word.uppercase())
}
MATLAB · script
while true
    word = string(input("Word: ", "s"));
    if word == "quit"
        break
    end
    if strlength(word) == 0
        continue
    end
    disp(upper(word));
end

Read text deliberately. input(prompt, "s") returns a character vector; string converts it to a string scalar. Without "s", input evaluates the entered text as a MATLAB expression. For numeric text, use str2double and check for NaN. break exits the nearest loop; continue skips to its next iteration.
