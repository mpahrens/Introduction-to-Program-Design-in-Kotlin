Use Kotlin's Math Library

Kotlin's math library supplies familiar constants and operations that can be combined into larger expressions.

Necessary 2-3 minutes Microskills: import, PI, pow

Import the Names You Need

The math library includes the constant PI and the method pow for raising a number to a power. Import them at the top of the file:

import kotlin.math.PI
import kotlin.math.pow

PI is a Double value. The pow method is called on a Double using dot notation. Its argument is the exponent.

3.0.pow(2)   // 9.0
2.0.pow(3)   // 8.0

Build a Formula from Named Pieces

For example, the area of a circle is pi times the radius squared. A Kotlin program can name the radius, then use that name in the formula:

val radius = 2.5
val area = PI * radius.pow(2)
println(area)

The formula is one expression built from smaller expressions: PI, radius, and radius.pow(2). Naming the inputs and result makes the structure visible.

Keep Units and Types in Mind

Geometry formulas commonly use Double values because measurements may have decimal parts. Kotlin will compute the formula, but it cannot know whether a number represents centimeters, meters, or something else. Meaningful names and surrounding documentation carry that information.
